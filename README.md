A single self-contained one-liner for the make.fun "One Line, One Laugh" bounty. `main.py` writes one funny line (123 characters, inside the 1–140 gate) to `/output/entry.txt`; a built-in gate check fails loudly if the line ever drifts out of spec.

## Run it

```sh
python3 main.py
```
